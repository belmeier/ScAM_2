This simple app was built from scratch with the help of Gemini. 
The idea is to create an app that allow auto-fix any photo (especially) receipt that need to be forwarded to other people for payment sharing. 
Because it is still simple, the main function is only use some Apple's Vision Framework (VNDetectRectanglesRequest, VNRectangleObservation, and VNImageRequestHandler)
The purpose is not on the encoding but how the students can use Vision's features into a useful app.
